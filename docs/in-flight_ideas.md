# In-flight ideas

Scratchpad for ideas under consideration — questions, not commitments (see the
handbook's `documentation.md`). Don't act on an entry silently.

## When does Research (M6) start reading the knowledge-gap queue?

`wiki.find_gaps` / `wiki.report_gap` already populate a knowledge-gap queue in
Phase 1. `docs/plan.md` places the Research system (M6), the consumer of that
queue, in Phase 2. Is the queue meant to accumulate unread until Phase 2
begins, or is there value in a lighter, earlier consumer (even a manual
review of the queue) before M6 lands?

## What triggers the move from Phase 1 to Phase 2?

`docs/plan.md` scopes Research, Cogitate, and Curate to Phase 2, with Phase 1
(Ingest / Retrieve / Converse) as the milestone this repo currently ships.
What marks Phase 1 as done enough to start Phase 2 — a milestone list, a
usage threshold on the shipped daemon, or the maintainer's own judgement? An
explicit trigger would let the README state a current condition rather than
an open-ended "next."
